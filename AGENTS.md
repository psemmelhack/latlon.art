## Development

When starting the dev server, use background mode and the project port:

```
astro dev --background --host 0.0.0.0 --port 4391
```

The site is served at http://127.0.0.1:4391

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
